# 素材准备清单

> 你只需要往这个 `素材` 文件夹里丢文件。不确定的地方全部留空/写得潦草都行，我来整理。
> 也可以完全不碰这些文件夹，直接甩一个网盘链接给我。

---

## 一、最少投入（做完这些我就能做出第一版）

1. **3 件代表作**（先做 3 件，看到样子后你再批量补剩下的）
2. **一段自我介绍**（100~300 字，口语化随便写，我来润色）
3. **头像**一张（正方形，≥800px）
4. **联系方式**：邮箱 + GitHub / 小红书 / B站 / 微信二维码 等，有几个给几个

---

## 二、每个作品建一个文件夹

放在 `素材\作品\` 下面，命名格式：`序号-作品名`

```
素材\作品\
├─ 01-作品名
│  ├─ 封面.jpg
│  ├─ 01.jpg
│  ├─ 02.jpg
│  └─ 说明.txt
└─ 02-作品名
   └─ ...
```

**说明.txt 里写这些（有几项写几项，没有就写"没"）：**

- 标题：
- 一句话简介：（列表卡片上显示的那句）
- 详细描述：（做了什么事、解决了什么问题、亮点）
- 我的角色：（独立完成 / 团队里负责 XX）
- 时间：（2024.06 这种格式）
- 工具/技术：（Figma、Blender、React…）
- 链接：（GitHub / 在线预览 / 视频）

---

## 三、图片规格

- 宽度 **1600~2400px**，JPG / PNG / WebP 都行
- 每件作品 **3~6 张**（1 张封面 + 若干细节图）
- 横图竖图混着放没关系，不用自己裁切和压缩，我来统一处理
- 图片别改成一堆奇怪的名字，`01.jpg` `02.jpg` 这种最好

---

## 四、不要放的东西

- 单个超过 **30MB** 的视频 → 给我 B站 / YouTube / 网盘链接就行
- PSD / AI / FIg 源文件 → 不需要，导出图片即可
- 手机上截图的那种图 → 尽量给原图

---

## 五、需要你拍板的 4 件事

1. **网站主要给谁看**：求职作品集 / 接单获客 / 个人品牌 / 纯归档
2. **部署在哪**：免费托管（GitHub Pages、Vercel）/ 国内服务器（要备案）/ 先只在本地看
3. **语言**：中文 / 中英双语 / 英文
4. **以后你怎么改内容**：让我改 / 你自己改 Markdown / 想要一个可视化后台

---

## 六、我负责的部分（你不用管）

脚手架、页面设计与响应式、动效、暗色模式、SEO 与分享卡片、图片压缩与格式转换、路由与 404、性能优化、部署配置、README 和后续维护说明。
