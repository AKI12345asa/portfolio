# 02-1 技能编辑器

## 一句话定位

把 `SkillClip` 的六类帧数据画成横向时间轴轨道（动画、音效、特效、攻击检测、自定义事件、相机事件），并在专用场景里用一个被剥掉逻辑的临时角色做**采样式预览播放**。

> 35 个 `.cs`、5404 行；编辑器类全部未声明命名空间。

## 使用流程

1. **开窗**：菜单 `SkillEditor/UI Toolkit/SkillEditorWindow`，克隆 `SkillEditorWindow.uxml` 后依次 `InitTopMenu / InitTimeShaft / InitConsole / InitContent / InitSkillConfigInspector`，并注入 `SkillClip.SetValidateAction`。
2. **进场景**：记住旧场景后打开 `SkillEditorScene.unity`，在根物体中找 `PreviewCharacterRoot`。
3. **选角色**：`CharacterConfigField` 选 `ISkillOwner`，实例化其 `SkillOwnerGameObject`、`StripPreviewComponents` 剥组件、`PreviewModel = Animator 所在物体`，下拉填充 `SkillName`。
4. **选技能**：下拉选 `SkillConfig` → `ListView` 列 `Clips` → 拖 `SkillClip` 到 `SkillConfigObjectField`；切换时先存盘，再重置帧号、`FrameCount`、`ResetTrack()`、`TickSkill()`。
5. **编辑**：拖资源进轨道、点事件轨道空白建事件、拖条目改帧、多行轨点「+」加子轨、拖表头换序。
6. **预览**：`▶` 播放/暂停、`<`/`>` 步进、拖刻度擦洗、滚轮缩放。
7. **保存**：`SaveConfig()` = `SetDirty` + `SaveAssetIfDirty`，高频路径走 0.3s 去抖，`OnDisable` 兜底。

## 关键机制详解

### 1. 轨道体系：Menu/Content 双树 + 外观层

右侧 `MainContentView` 里只有一条 `ContentListView`，宽度 = `FrameUnitWidth * FrameCount`；左侧 `TrackMenuScrollView` 只放表头，两条 `ScrollView` 的 `verticalScroller.valueChanged` 互相赋值以同步垂直滚动。一条轨道 = **行为 + 外观**：`SkillTrackBase` 子类只管建/删/刷/播，DOM 由 `SkillTrackStyleBase` 子类实例化 UXML 后同时挂到 `MenuParent` 与 `ContentParent`，所以新增轨道几乎不用写视图代码。

### 2. 三种条目放置语义

- **按帧做 Key 的字典**（动画/事件轨道）：一格最多一个事件，拖动时 `Remove(old)` 再 `TryAdd(new)`，冲突回滚。
- **顺序列表**（音效/特效/检测/相机）：每个元素独占一行 `ChildTrack`，行序即列表序，拖表头同时交换 UI 与数据。
- **一行一个条目**：`ChildTrack.InitContent(Root)` 把条目根节点塞进该行内容区，条目坐标是相对该行的 X 偏移。

### 3. 时间轴交互：帧与像素的单点换算

换算只有两个入口：`GetFrameIndexByPos(x) = RoundToInt(x / FrameUnitWidth)`、`GetFrameIndexByMousePos(x)`（默认加 `ContentOffsetPos`，即已被水平滚动掉的像素）。这就是"吸附"的全部：**只吸整帧格，无磁性吸附**。

- 拖刻度：`MouseDown` 先停播再按 X 求帧，`MouseMove` 在进入态持续更新，形成擦洗。
- 缩放：`WheelEvent` 里 `FrameUnitWidth = Clamp(旧值-delta, 10, 100)`，随后 `ResetTrack()`（**全量重建条目**）。刻度由 `Handles.DrawLine` 画在 `IMGUIContainer` 上，`tickStep` 决定每隔几帧标数字；`SelectLine` 单独画选中竖线。
- 拖条目：`MouseDown` 记起点，`MouseMove` 按 `RoundToInt(dx / FrameUnitWidth)` 算帧并即时 `ResetView`，`MouseUp/Out` 校验写回；动画条目还要过"不与其他动画区间重叠"的三重校验，失败回退。

### 4. 选中与 Inspector 联动

点条目 → `TrackItemBase<T>.Select()` → `ShowTrackItemOnInspector` → `SkillEditorInspector.SetTrackItem`（先 `OnUnSelect` 旧的）→ 关键一步 `Selection.activeObject = this`，把**窗口自身**设为选中对象，从而驱动 `[CustomEditor(typeof(SkillEditorWindow))]` 的 `Show()`；它按条目类型 `switch` 出面板，`Draw(root,item,track)` 做泛型强转，`OnDraw()` 才开始建控件。

### 5. 事件面板与条目的双向同步

"**即时写 + 重建式读**"，无 MVVM：控件回调直接改 `trackItem.XXXEvent.Field`（同一对象引用），随后按需 `SaveConfig()`/`RequestSaveConfig()`、`ResetView()`、`TickSkill()`；反向不监听数据，一律靠重建面板或重建条目视图。数值多用 `FocusIn` 存旧值、`FocusOut` 比对后提交，Scene 手柄这类连续改值的走去抖保存。条目拖动后调 `SetTrackItemFrameIndex` 同步面板的 `ItemFrameIndex`，保证"删除""设置帧数到当前选中帧"作用在正确 Key 上。

### 6. 预览播放的完整流程

1. `PlayButtonClicked` → `IsPlaying = !IsPlaying`。置 true 时记 `_startTime = DateTime.Now`、`_startFrameIndex`，并遍历轨道调 `OnPlay(当前帧)`。
2. `OnPlay` 是"从中间起播"的补偿：`AudioTrack` 算出播放头落在 clip 内部的偏移并带进度试听；`CameraEventTrack` 复位上次预览、给虚拟相机拍快照（位置/旋转/FOV/Priority）并把 `Priority` 抬到 10000 抢镜，再立刻 `TickView` 一次。
3. `EditorWindow.Update` 每帧推进：`帧 = (Now - _startTime) * SkillClip.FrameRate + _startFrameIndex`；等于 `CurrentFrameCount` 时自动停。
4. `CurrentSelectFrameIndex` 的 setter 是唯一驱动点：clamp → 更新 `IntegerField` → `UpdateTimerShaftView()` 重绘 → `TickSkill()`。
5. `TickSkill()` 仅在 `SkillClip` 与预览角色都存在时遍历轨道 `TickView(frame)`。
6. 各轨道：动画=采样姿态+根运动位移；音效=命中帧才播；特效=按 `(frame-FrameIndex)/FrameRate` 调 `ParticleSystem.Simulate` 追赶；相机=还原基线后按序叠加（旋转 Slerp、FOV Lerp、震动 impulse）；攻击检测**无 TickView**，只在 Scene 画 Gizmos 与手柄。
7. 暂停即 `OnStop()`（音频未实现、相机只清去重集合）；拖时间轴与步进都强制停播，**不支持边播边擦洗**。
8. `[DidReloadScripts]` 触发 `ClearPreviewAfterScriptsReload()`，清角色、相机状态与轨道。

### 7. 预览用的临时对象 / Animator / 相机

- **角色**：`StripPreviewComponents` 按白名单剥组件，只留 `Transform / Animator / Animation_Controller / Cinemachine* / SkillChecker / Collider` 和 `GetRemainingComponentWhenPlay()` 返回的类型（Demo 只返回 `Skill_Player`），得到"有挂点有 Animator、无战斗逻辑"的壳。
- **Animator**：预览不走状态机，而是 `AnimationClip.SampleAnimation(PreviewModel, 时间)`；`UpdatePosture` 向左找最近动画事件算 `progress`（循环取模、非循环 clamp01）并 `SetMainWeaponHand`；`GetPositionForRootMotion` 临时开 `applyRootMotion` 采样累加位移，再写回 `PreviewModel.position`。
- **相机**：优先用 `_currentSkillCamera`，否则 `_skillOwner.GetSkillCamera(预览对象)`；相机事件全作用于这台 Cinemachine 相机，由 `CameraPreviewState` 快照与还原。
- **特效**：`EffectParent = GameObject.Find("Effects")`。

## 扩展一种新事件类型（手把手）

1. **数据**：`MyNewEvent`（含 `int FrameIndex = -1`，编辑器字段用 `#if UNITY_EDITOR` 包）+ 容器 `MyNewData { List<MyNewEvent> FrameData }`。
2. **挂资产**：`SkillClip` 里加 `[NonSerialized, OdinSerialize] public MyNewData MyNewData = new();`（这一对特性必须照抄，否则 Odin 不序列化）。
3. **轨道**：`MyNewTrack : SkillTrackBase`，`Init` 里建 `SkillMutilineTrackStyle` 并传 4 个回调（增/删/换序/改名），重写 `ResetView`/`Destroy`，按需 `TickView/OnPlay/OnStop/DrawGizmos/OnSceneGUI`；回调里要同时改数据并 `SaveConfig()`。
4. **条目**：`MyNewTrackItem : TrackItemBase<MyNewTrack>`，`Init` 里建 Style 并给 `MainDragArea` 注册四个鼠标事件，`ResetView` 里 `SetWidth/SetPositionX`。
5. **外观**：`MyNewTrackItemStyle : SkillTrackItemStyleBase`，实例化 uxml 得 `Root`，暴露 `IsInit` 与 `MainDragArea`（可复用 `AudioTrackItem.uxml`），末尾 `_childTrack.InitContent(Root)`。
6. **面板**：`SkillMyNewEventInspector : SkillEventDataInspectorBase<TItem,TTrack>`，`OnDraw` 建控件，回调直接写数据并 `SaveConfig()` + `ResetView()` + `TickSkill()`；删除调 `track.DeleteTrackItem(ItemFrameIndex)`。
7. **注册两处**：`InitTrack()` 加 `InitMyNewTrack()`（`new` → `Init(_trackMenuParent, _contentListView, FrameUnitWidth)` → `_trackList.Add`）；`SkillEditorInspector.Show()` 的 `switch` 加一个 `case`。

**相机事件例外**：`[CameraEvent(路径)]` 加 `[CameraEventInspector(typeof(T))] CameraEventInspectorItem<T>`，`TypeCache` 会自动纳入「+」下拉、面板映射与帧驱动，无需改上面两处。

## 与运行时战斗系统的耦合

- **共享资产**：`SkillClip` 既是编辑器编辑对象，也是运行时 `PlaySkillClip` 的输入。
- **编辑器字段被隔离**：`DurationFrame`、各事件 `TrackName`、`AttackDetectionType` 都在 `#if UNITY_EDITOR` 内；运行时检测类型由 `AttackDetectionData` 的实际类型反推。
- **帧率同源**：所有帧↔秒换算都用 `SkillClip.FrameRate`。预览不调 `PlaySkillClip`、不跑 `SkillBehaviourBase` / `DetectionEventProcessor`，`Skill_Player` 只当零件表（`checkerDic` 取武器、`SetMainWeaponHand` 换手、`SkillGizmosTool` 画检测体）。
- **相机预览绕过运行时 `SkillCamera`**，直接抢 Priority + 硬写 transform/FOV。

## 设计亮点与可改进点

**亮点**

- 四层分离：行为、DOM、条目、面板，新增轨道基本是填空。
- 单一换算入口 `FrameUnitWidth` 让缩放/滚动/拖拽/擦洗共用，只需补偿 `ContentOffsetPos`。
- 复用窗口的 CustomEditor 做事件面板，省掉独立窗口并获得 Inspector 焦点语义。
- 相机事件靠属性 + `TypeCache` 策略注册，新增零 switch。
- 兜底：去抖保存、重载清预览、`OnValidate` 反刷轨道。

**可改进**

- `TransitionFieldFocusIn` 把 `_durationField.value` 存进 `_oldTransitionValue` 再与过渡字段比较，**旧值基准取错控件**，该字段很可能改不动。
- `InitEffectTrack` 拿 `scene.path != "PreviewCharacterRoot"` 做条件恒为真 → `ClearEffects()` 永不执行。
- `CameraEventTrack.OnStop` 不复位相机 Priority 与姿态（仅在 `Destroy`/`ClearPreviewState` 复位）；停播后相机是否仍被 10000 占用 —— ⚠ 待确认。
- `EventTrackItem.CurrentSelectItem` 与 `SkillEditorInspector.CurrentTrackItem` 两套选中并存，`EventTrack` 靠前者判断新增还是移动，不一致时行为 —— ⚠ 待确认。
- 时间推进用 `DateTime.Now` 且直接触发全量 `TickSkill`，无降频；缩放全量重建条目；反射 `UnityEditor.AudioUtil` 有升级失效风险。
- 无任何 `KeyDownEvent` 注册，删除只能点按钮；`SkillEffectTrackItemStyle .cs` 文件名夹空格。
